# homeuu 部署指南

按顺序做完下面 5 步即可使用。对应[方案](方案.md)第 7 节的阶段 0–2。

## 第 1 步：部署服务器

准备一台有公网 IP 的 Linux 云服务器（Ubuntu 22.04/24.04、Debian 12 均可，1 核 1G 够用）。

```bash
# 以 root 登录服务器后执行
curl -fsSLO https://raw.githubusercontent.com/huangyu19890101/uu/main/server/install.sh
HOMEUU_PUBLIC_HOST=<服务器公网IP> bash install.sh
```

> 仓库是私有的话，上面的 raw 链接下载不了，把 `server/install.sh` 复制到服务器上再运行即可。
> 服务器访问不了 GitHub 时：在自己电脑上下载 [rustdesk-server-linux-amd64.zip](https://github.com/rustdesk/rustdesk-server/releases/download/1.1.16/rustdesk-server-linux-amd64.zip)，上传到服务器，再用 `HOMEUU_ZIP=<zip路径> HOMEUU_PUBLIC_HOST=<IP> bash install.sh`。

脚本结束时会打印三项内容，**记下来**：

| 输出 | 例子 | 用途 |
|---|---|---|
| ID 服务器 | `1.2.3.4:31116` | GitHub Secret `HOMEUU_SERVER` |
| 中继服务器 | `1.2.3.4:31117` | GitHub Secret `HOMEUU_RELAY` |
| Key | `A45g8+H8...hNY=` | GitHub Secret `HOMEUU_KEY` |

然后在云厂商控制台的**安全组**里放行入方向：TCP 31115、31116、31117，UDP 31116。

最后备份私钥 `/var/lib/homeuu-server/id_ed25519`（加密保存）。换服务器时把它放回同一位置，客户端就不用重新编译。

常用命令：

```bash
systemctl status homeuu-hbbs homeuu-hbbr        # 状态
journalctl -u homeuu-hbbs -u homeuu-hbbr -f     # 日志
bash install.sh --uninstall                     # 卸载（保留密钥）
```

## 第 2 步（可选）：先用官方客户端验证

编译定制版前，可以先用 [RustDesk 官方客户端](https://github.com/rustdesk/rustdesk/releases) 验证服务器：两台电脑都在"设置 → 网络 → ID/中继服务器"里填入第 1 步的 ID 服务器、中继服务器和 Key，然后互相连接。连接窗口显示"安全连接"即说明服务器正常。

## 第 3 步：编译 homeuu

1. 打开仓库 **Settings → Secrets and variables → Actions → New repository secret**，添加 `HOMEUU_SERVER`、`HOMEUU_RELAY`、`HOMEUU_KEY` 三个 Secret（值见第 1 步）。
2. 打开 **Actions → Build homeuu → Run workflow**，勾选要编译的平台后运行。一次大约 1 小时。
3. 完成后在运行页面底部的 **Artifacts** 下载：
   - `homeuu-windows-x64`：内含 `homeuu-1.5.1-windows-x64.msi`
   - `homeuu-macos-arm64`：内含 `homeuu-1.5.1-macos-arm64-unsigned.dmg`

服务器地址、端口、Key 和功能锁定都在编译时写入，安装后不需要再配置。要改端口，同时改服务器（`HOMEUU_PORT`、`HOMEUU_RELAY_PORT`）和 [client/homeuu.json](../client/homeuu.json)，再重新编译。

## 第 4 步：安装 Windows 版（主要被控端）

1. 双击 `homeuu-...-windows-x64.msi` 安装。安装包会把 homeuu 注册为 Windows 服务（LocalSystem、开机自动启动），未登录、锁屏、UAC 弹窗时都能被控制。
2. 打开 homeuu → 设置 → 安全：
   - **设置永久密码**（强密码，和 Mac 的不同）。编译时已锁定为"只用永久密码"，没设密码前别人和你自己都连不上。
   - 开启**双重认证（2FA）**，用手机验证器 App 扫码。
3. 电源设置里关闭自动睡眠。
4. 记下主界面上的 ID。

## 第 5 步：安装 Mac 版

### 5.1 获取免费签名证书（只需一次）

1. 从 App Store 安装 Xcode 并打开一次。
2. Xcode → Settings → Accounts → 左下角 `+` → 用你的 Apple ID 登录。
3. 选中账号 → Manage Certificates → 左下角 `+` → **Apple Development**。
4. 终端执行 `security find-identity -v -p codesigning`，能看到 `Apple Development: ...` 即成功。

### 5.2 签名并安装

```bash
bash client/sign-macos.sh ~/Downloads/homeuu-1.5.1-macos-arm64-unsigned.dmg
```

脚本会用你的证书签名并装到 `/Applications/homeuu.app`。以后升级也用同一条命令，**一直用同一个证书**，系统权限才不会丢。

### 5.3 授权与无人值守

1. 打开 homeuu，按提示在"系统设置 → 隐私与安全性"里授予**屏幕录制**和**辅助功能**权限（有提示时也授予输入监控）。
2. 在 homeuu 里按提示**安装服务**（输入管理员密码），这样登录窗口和锁屏时也能被控制。
3. 设置永久密码和双重认证，同 Windows。
4. 按方案的决定：系统设置 → 隐私与安全性 → **关闭 FileVault**；系统设置 → 用户与群组 → **开启自动登录**。这样 Mac 重启后会自动上线。

## 使用

- 在 Mac 的 homeuu 里输入 Windows 的 ID，输入永久密码和验证码即可连接。
- Mac 控 Windows 时，在会话顶部工具栏的键盘菜单里打开 **Swap control-command key**，Command+C/V 就能当 Ctrl+C/V 用。
- 连接窗口必须显示"安全连接"。如果提示不安全连接，不要点继续，检查 Key 是否一致。

## 已锁定的设置

编译时写入、界面上改不了（见 [client/homeuu.json](../client/homeuu.json)）：

- 只保留画面、键盘鼠标、文本剪贴板；关闭文件传输、音频、摄像头、终端、TCP 隧道、远程打印、录屏、隐私模式、远程修改配置。
- 只接受永久密码。
- 关闭自动更新和更新检查。升级方式：重新编译、手动安装，保留上一版安装包以便回退。

## 验收

按[方案](方案.md)第 8 节的测试清单逐项验证。以下几项必须真机确认：

- [ ] Windows：未登录、锁屏、UAC 弹窗三种状态下都能看到画面**并能操作**
- [ ] Mac：锁屏后能远程解锁；注销后能在登录窗口远程登录；重启后无人操作能连上
- [ ] 直连和中继两种情况都显示"安全连接"
- [ ] 正确密码 + 错误验证码会被拒绝
- [ ] 升级（重新签名安装）后 Mac 权限还在
